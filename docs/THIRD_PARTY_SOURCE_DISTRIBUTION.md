# Third-party source distribution

The macOS application bundle contains Espressif QEMU and dynamically linked
runtime libraries. Every public binary release must publish the matching
third-party source bundle generated by:

```sh
./scripts/prepare-third-party-sources.sh
```

Upload the resulting
`StickS3-Firmware-Lab-v0.1.0-beta-third-party-sources.zip` and its SHA-256 file to
the same GitHub Release as the macOS application. Do not publish the binary
without these companion files.

The bundle contains the exact source releases for:

- Espressif QEMU `esp-develop-9.2.2-20250817`, tag commit
  `4f4148e2f68689eb8861bf9fce0b46ada9200fef`;
- GNU gettext 1.0;
- GLib 2.88.3;
- libgcrypt 1.12.2;
- libgpg-error 1.61;
- PCRE2 10.47;
- pixman 0.46.4; and
- SDL2 compatibility 2.32.70.

The script verifies every archive checksum, verifies the QEMU tag commit before
using its source archive, and writes a final SHA-256 manifest. It reuses
`~/Downloads/esp-develop-9.2.2-20250817.tar.gz` when present; another reviewed
local path can be provided through `QEMU_SOURCE_ARCHIVE`.
